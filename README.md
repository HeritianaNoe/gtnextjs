# Mitady Teny

Lalao mitady teny amin'ny teny malagasy (Next.js App Router).

```bash
npm install
npm run dev
```

Alefaso ao amin'ny http://localhost:3000

Tabilao 10x10 ihany no misy (tsy misy haavo). Ovay ao amin'ny `data/puzzles.json` ny teny, ny haben'ny tabilao (`gridSize`),
ny isan'ny teny (`wordCount`) ary ny lalana azo ampiasaina (`directions`, [andalana, tsanganana]).
Soraty amin'ny litera lehibe tsy misy tsipika ny teny.
